# sony-headphones-client

An unofficial desktop client for Sony headphones on Windows, macOS and Linux.

It aims to talk to connected headphones over Bluetooth and expose their features, such as noise cancelling and ambient modes, EQ and battery status.

**Status:** planning. No code yet.

## Goals

- Cross-platform desktop app (Windows, macOS, Linux)
- Control the headphones' features without the official mobile app
- Test without hardware, using a mock device

## Target devices

- Sony WH-1000XM4
- Two more models, to be decided
